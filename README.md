# RavenBlast

Bulk email sender with an Outlook-style composer. Built for business owners.  
Windows 11 desktop app — all local, no cloud dependency.

## Stack

Electron · React · TypeScript · Vite · TipTap · nodemailer · SheetJS · electron-store
